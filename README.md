# 🚀 Employee Management System (EMS)

Ek modern aur responsive **Employee Management System** jo HR aur Employees ke beech ke workflow ko automate aur simplify karta hai. Isme Admin aur Employee panels ke liye alag-alag dashboards diye gaye hain.

---

## 📌 Key Features

### 👨‍💼 Admin Panel (Control Center)
Admin ke paas poore system ka access hai, jisme wo niche di gayi cheezein manage kar sakta hai:

* **Dashboard Overview**: Total employees, departments, aur pending leave requests ka live status.
* **Employee Management**: Naye employees ko register karna, unki details update karna, aur salary set karna.
* **Department & Leave Types**: Company ke departments (jaise Marine Engineering, R&D) aur leave categories (Sick, Casual, WFH) ko manage karna.
* **Salary Management**: Monthly salary records generate karna aur payment status track karna.
* **Leave Requests**: Employees dwara bheji gayi leaves ko Approve ya Reject karna.
* **Attendance & Reports**: Daily attendance mark karna aur registration/department-wise reports nikalna.

### 👨‍💻 Employee Panel (Self Service)
Employees apne account se niche diye gaye kaam kar sakte hain:

* **Personal Dashboard**: Apni profile details aur leave summary dekhna.
* **Apply Leave**: Online leave application form bharna aur apni leave history track karna.
* **Attendance Tracking**: Monthly attendance calendar check karna.
* **Salary History**: Apni purani salary records dekhna aur **Payslips** download karna.
* **Profile Update**: Personal information jaise address aur contact details update karna.
